문서함 새 서명 요청 문서 검증 설정

설정

교육생에게 메일을 보내려면 1·2번을 먼저 정해 주세요. 3번은 선택입니다.

1. 서명 링크 주소

메일 속 "서명하기" 버튼이 열 주소입니다. 교육생이 있는 곳에서 열 수 있는 주소여야 합니다.

어떤 주소를 넣어야 하나요?
  • 교육장 같은 Wi-Fi에서만 서명: 서버를 npm run start:lan으로 켜면 자동으로 이 PC의 내부 주소가 쓰입니다. 비워 두세요.
  • 집 등 외부에서 메일로 서명: 인터넷에서 열리는 주소가 필요합니다. HTTPS 서버에 올리거나, Cloudflare Tunnel 같은 터널로 이 PC를 임시 공개한 뒤 그 주소(https://…)를 넣으세요.

2. 메일 발송 계정

이 계정으로 교육생에게 서명 요청 메일이 나갑니다.

비밀번호는 이 PC의 data/settings.json에만 저장되며 화면으로 다시 보내지 않습니다.

3. 타임스탬프 (선택)

서명 완료 PDF에 공인 시각 확인 기관(TSA)의 타임스탬프를 붙입니다. 서명 시각을 이 PC의 시계가 아니라 외부 기관이 증명해 주므로, 나중에 "언제 서명했는지"를 다툴 때 더 강한 증거가 됩니다 (PAdES B-T).

무료 공용 TSA 예: http://timestamp.digicert.com, http://timestamp.sectigo.com. 서버로는 문서 내용이 아니라 서명값의 해시(지문)만 전송됩니다.

4. 보관 기간 (개인정보 파기)

요청이 끝난 날(만든 날·서명 기한·마지막 서명 중 가장 늦은 날)부터 정한 기간이 지나면 교육생 정보·서명 이미지·서명 완료 PDF를 자동으로 영구 삭제합니다. 각 요청 화면에서 직접 지울 수도 있습니다.

파기 기록

개인정보 없이 무엇을(제목·인원) 언제 왜 지웠는지만 남깁니다. 최근 50건.
