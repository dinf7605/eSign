문서 검증

서명 완료 PDF를 올리면 ① PDF 안의 전자서명과 ② 등록된 문서 지문(SHA-256)을 함께 확인합니다.
전자서명 검사를 위해 파일을 서버로 잠시 보내지만 저장하지 않고 검사 후 바로 버립니다.

Adobe Acrobat Reader에서 확인하기

서명 완료 PDF를 Acrobat Reader로 열면 상단에 서명 정보가 표시됩니다. 지금은 자체 발급 인증서라서 처음에는 "서명자 신원을 알 수 없음"으로 나옵니다. 아래 루트 인증서를 한 번 신뢰로 등록하면 초록색 체크로 바뀝니다.

  1. 서명 완료 PDF를 열고 서명 패널에서 서명을 오른쪽 클릭 → 서명 속성 표시
  2. 서명자 인증서 표시 → 인증서 목록에서 맨 위 e서명 루트 CA 선택
  3. 신뢰 탭 → 신뢰할 수 있는 인증서에 추가 → "인증된 문서" 신뢰에 체크 후 확인
루트 인증서 내려받기 (.crt)
