e서명 전자서명 서비스 — 운영 안내
==================================

[폴더 놓기] (처음 한 번)
  1. 이 폴더(e서명)를 통째로 C:\e서명 에 복사하세요.
     - C:\Program Files 안에서는 실행되지 않습니다(저장 권한 없음).
     - 바탕화면·OneDrive 폴더는 개인정보가 클라우드로 동기화되므로 피하세요.
  2. 서버로 쓸 PC는 서명 기간 내내 켜 두어야 합니다.
     Windows 설정 → 시스템 → 전원 → 절전 모드를 "안 함"으로 바꾸세요.

[실행]
  eSign.exe 를 더블클릭하세요.
  - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
  - 검은 창에 "인터넷 공개 주소: https://....trycloudflare.com" 이 나오면 준비 완료입니다.
  - 관리자 화면(http://localhost:3300)이 브라우저로 자동으로 열립니다.
  - 검은 창을 닫으면 서비스가 꺼집니다. 서명이 끝날 때까지 닫지 마세요.

[처음 한 번 설정] (관리자 화면에서)
  1. 관리자 비밀번호 만들기
  2. 설정 → 메일: 보내는 Gmail 주소와 "앱 비밀번호"(16자리) 입력 → 테스트 메일 보내기
     앱 비밀번호 만들기: https://myaccount.google.com/apppasswords (2단계 인증이 켜져 있어야 함)
  3. 설정 → 보관 기간: 개인정보 자동 파기 기간 (선택)

[주의]
  - 프로그램을 껐다 켜면 인터넷 주소가 바뀝니다. 이미 보낸 링크가 열리지 않으니,
    다시 켠 뒤 교육생 현황에서 "미서명자에게 다시 알림"을 누르세요.
  - 관리자 화면은 이 PC에서만 열립니다. 교육생은 메일 속 링크로 서명 화면만 봅니다.

[data 폴더] (eSign.exe 옆에 자동으로 생김)
  서명 요청·교육생 개인정보·서명 PDF·메일 비밀번호·문서 봉인 개인키가 모두 들어 있습니다.
  - 백업: 프로그램을 끄고 data 폴더를 통째로 USB 등 안전한 곳에 복사하세요.
  - 공유 폴더·메신저로 보내지 마세요.
  - 관리자 비밀번호를 잊으면: 프로그램을 끄고 data\admin.json 을 지운 뒤 다시 실행해 새로 만드세요.
  - 새 버전 eSign.exe 로 바꿀 때는 exe 파일만 바꾸고 data 폴더는 그대로 두세요.

[다른 실행 방법] (명령 프롬프트에서)
  eSign.exe --local   이 PC에서만 (인터넷 공개 안 함)
  eSign.exe --lan     같은 Wi-Fi의 휴대폰에서 서명
