# e서명 — 교육생 전자서명 서비스

교육생마다 **메일로 서명 링크를 보내고 → 교육생은 이름+전화번호로 본인 확인 후 서명 → 개인별 서명 PDF가 저장되고 → 서명한 사람 명단(엑셀/PDF)을 뽑는** 웹 서비스입니다.
계약서처럼 한 문서에 여러 명이 함께 서명하는 방식도 지원합니다.

## 실행

```bash
cd esign
npm install
npm start            # 이 PC에서만: http://localhost:3300
npm run start:lan    # 같은 Wi-Fi의 교육생 휴대폰에서도 접속
npm test             # 자동 테스트
npm run mail-catcher # 연습용 가짜 메일 서버 (실제로 안 보내고 파일로 저장)
```

처음 `http://localhost:3300`에 들어가면 **관리자 비밀번호**를 만듭니다(서버를 켠 PC에서만 가능).

## 처음 한 번: 설정 (상단 메뉴 "설정")

### 1) 메일 발송 계정
| 메일 서비스 | 준비할 것 |
| --- | --- |
| Gmail | Google 계정 → 보안 → 2단계 인증 켜기 → **앱 비밀번호** 만들어 비밀번호 칸에 입력 |
| 네이버 메일 | 메일 환경설정 → POP3/IMAP 설정 → **IMAP/SMTP 사용** 켜기 (2단계 인증 중이면 애플리케이션 비밀번호) |
| 다음/카카오 | 메일 환경설정 → IMAP/SMTP 사용 켜기 |
| 회사 메일 | 메일 담당자에게 SMTP 서버·포트·보안 방식을 받아 "직접 입력" |

저장한 뒤 **테스트 메일 보내기**로 본인 메일함에 도착하는지 확인하세요. 비밀번호는 `data/settings.json`에만 저장되고 화면으로 다시 보내지 않습니다.
Gmail은 하루 약 500통까지 보낼 수 있습니다.

### 2) 서명 링크 주소 — 교육생이 메일 속 링크를 **어디서** 여는지에 따라 다릅니다

| 상황 | 방법 |
| --- | --- |
| 교육장 안, 같은 Wi-Fi | `npm run start:lan`으로 실행. 주소는 자동(예: `http://192.168.0.12:3300`). Windows 방화벽 창이 뜨면 **개인 네트워크**만 허용 |
| 집 등 어디서나 | 인터넷에서 열리는 주소가 필요합니다. ① HTTPS 서버(클라우드 등)에 이 프로그램을 올리거나, ② Cloudflare Tunnel 같은 터널로 이 PC를 임시 공개한 뒤 그 `https://…` 주소를 설정에 입력 |

주소가 `localhost`이면 메일 발송이 막힙니다(받은 사람이 열 수 없기 때문). 교육생 현황 화면에도 경고가 나옵니다.

### 3) 타임스탬프 (선택)

"타임스탬프 사용"을 켜면 서명 완료 PDF·명단 PDF를 봉인할 때 **공인 시각 확인 기관(TSA)** 에서 RFC 3161 타임스탬프를 받아 함께 넣습니다(PAdES B-T).
서명 시각을 이 PC의 시계가 아니라 외부 기관이 증명하므로, "언제 서명했는지"에 대한 증거가 강해집니다.

- 기본 주소: `http://timestamp.digicert.com` (무료). **연결 테스트**로 확인하세요. TSA로는 문서가 아니라 서명값의 해시만 전송됩니다.
- 인터넷이 필요합니다. TSA가 응답하지 않으면(8초) **타임스탬프 없이 봉인**하고, 문서 기록에 "타임스탬프 실패"가 남습니다. 서명이 막히지는 않습니다.
- 교육장에 인터넷이 없다면 꺼 두세요.

## 사용 순서

1. **새 서명 요청 → 교육생 일괄 서명**을 고르고 PDF(동의서·서약서 등)를 올립니다.
2. 교육명·교육 정보와 **명단**을 붙여넣습니다. 엑셀에서 `이름 / 소속 / 전화번호 / 이메일` 열을 복사하면 되고, 열 순서는 자유입니다.
   - 전화번호가 없거나 이메일이 없는 사람은 미리보기에 바로 표시됩니다.
   - **본인 확인 사용**(기본 켜짐): 서명 전에 이름+전화번호가 명단과 같아야 문서가 열립니다.
3. 문서 위에 `✍ 서명`(필수), `이름 (자동)`, `날짜 (자동)` 칸을 놓고 **서명 요청 만들기**를 누릅니다.
4. 현황 화면에서 **"안 보낸 N명에게 메일 보내기"**를 누릅니다. 교육생마다 **본인 전용 링크**가 담긴 메일이 갑니다.
   - 발송 결과(보냄/실패 이유)가 사람별로 보입니다. 주소가 틀렸으면 **수정** 후 그 사람만 **메일 다시**를 누르세요.
   - **미서명자에게 다시 알림**을 누르면 "[다시 알림]" 제목으로 다시 보냅니다.
   - 이메일이 없는 사람은 **QR**, **링크**, **이 기기에서**(현장 태블릿)로 받으세요.
5. 교육생: 메일 버튼 → **이름·전화번호 입력** → 문서 확인 → 서명 → 동의 → 제출. 그 즉시 개인별 **서명 완료 PDF**가 저장됩니다.
   - 하이픈·띄어쓰기·+82 형식은 달라도 됩니다. 5번 틀리면 15분 잠깁니다(담당자가 정보 확인 후 수정 가능).
6. **서명한 사람 명단** 내려받기 (현황 화면 오른쪽 위)
   - **명단 엑셀(.xlsx)**: 서명한 사람만 — 번호·이름·소속·전화번호·이메일·서명 일시·본인 확인 시각·메일 발송·IP·문서 해시
   - **명단 PDF**: 서명한 사람만 — 서명 이미지 포함, 전화번호 일부 가림, 전자서명 포함
   - "다른 내려받기": 미서명자까지 포함한 **전체 현황**(엑셀/PDF), **개인별 서명 PDF 전체(ZIP)**

개인별 서명 PDF에는 서명·이름·날짜, **감사 추적 인증서**(메일 발송, 본인 확인 성공/실패, 열람, 서명 시각·IP)와 PAdES 전자서명(타임스탬프를 켰다면 TSA 시각 포함)이 들어갑니다.

## 메일 연습하기 (실제로 보내지 않음)

```bash
npm run mail-catcher
```
설정 → 메일 서비스 "직접 입력" → SMTP 서버 `127.0.0.1`, 포트 `2525`, 보안 "없음", 보내는 사람 이메일 아무 주소.
보낸 메일은 `esign/.mail-catcher/*.eml` 파일로 저장되고, 더블클릭하면 Outlook·Windows 메일에서 열어 볼 수 있습니다.

## 보안

- 담당자 화면은 로그인이 필요합니다(비밀번호 scrypt 해시, 5회 실패 시 1분 잠금). 비밀번호를 잊으면 서버를 끄고 `data/admin.json`을 지운 뒤 서버 PC에서 다시 설정하세요.
- 서명 링크에는 추측할 수 없는 무작위 토큰이 들어 있고, 본인 확인 전에는 **누구의 링크인지·문서 내용이 보이지 않습니다**. 본인 확인 세션은 2시간 유지되며 그 사람 문서에만 쓸 수 있습니다.
- 이름+전화번호 확인은 "링크를 우연히 받은 다른 사람"을 막는 수준입니다. 서로 전화번호를 아는 사이라면 대신 서명할 수 있으므로, 더 강한 확인이 필요하면 휴대폰 문자 인증(유료 서비스 연동)을 고려하세요.
- `start:lan`·`http://` 주소는 암호화되지 않습니다. 외부 공개는 반드시 HTTPS 주소로 하세요.
- 엑셀 명단은 모든 값을 텍스트로 저장해 수식이 실행되지 않고, 전화번호 앞 0도 유지됩니다.

## 백업

모든 데이터는 `data/` 폴더 하나에 있습니다(`db.json`, `files/`, `keys/`, `admin.json`, `settings.json`). **서버를 끄고 `data/` 폴더를 통째로 복사**하면 됩니다. 이 폴더에는 메일 비밀번호·개인키·교육생 개인정보가 있으니 안전하게 보관하세요.

## 실행 옵션

| 옵션 | 설명 |
| --- | --- |
| `--lan` 또는 `HOST=0.0.0.0` | 같은 Wi-Fi에서 접속 허용 |
| `--port=3300` / `PORT` | 포트 |
| `--data=폴더` / `ESIGN_DATA_DIR` | 데이터 폴더 |
| `PUBLIC_URL` | 서명 링크 주소 고정 (설정 화면 값보다 우선) |
| `ADMIN_PASSWORD` | 관리자 비밀번호를 환경변수로 지정 |
| `ESIGN_FONT` | 한글 폰트 경로 (기본: 맑은 고딕) |
| `ESIGN_SEAL_KEY` / `ESIGN_SEAL_CERT` / `ESIGN_SEAL_CHAIN` | 공인 문서서명 인증서 사용 (기본: 자체 발급) |
| `ESIGN_TSA_URL` | 타임스탬프 기관 주소 고정 (설정 화면 값보다 우선) |

## PDF 전자서명 (PAdES)

- 형식: PAdES Baseline B-B (`ETSI.CAdES.detached`, SHA-256 / RSA-3072). 서명 뒤 1바이트라도 바뀌면 검증 실패.
- 타임스탬프를 켜면 **B-T**: 서명값에 대한 RFC 3161 타임스탬프 토큰을 서명의 비서명 속성(`id-aa-timeStampToken`)에 넣습니다. `/verify.html`에서 "서명 시각 — 타임스탬프로 확인됨"과 TSA 이름이 보입니다. TSA 인증서는 Node 내장 공인 루트 목록으로 신뢰 여부를 확인합니다.
- 기본 인증서는 자체 발급이라 Adobe Reader에서 처음엔 "신원 알 수 없음"으로 나옵니다. `/verify.html`에서 루트 인증서를 받아 신뢰로 등록하거나, 공인 문서서명 인증서를 지정하세요.
- `data/keys/*.key.pem`은 개인키입니다. 절대 공유하지 마세요.

## 구조

```
server.js            Express API (로그인·설정·문서·교육생 일괄·메일·본인 확인·서명·검증)
lib/auth.js          관리자 로그인
lib/settings.js      설정 저장 (서명 링크 주소, SMTP)
lib/mailer.js        메일 발송(nodemailer) + 서명 요청 메일 내용
lib/store.js         JSON 파일 저장소
lib/finalize.js      서명·이름·날짜 삽입 + 감사 추적 인증서 + PDF 전자서명
lib/roster.js        서명자 명단 PDF / 엑셀
lib/xlsx.js          엑셀(.xlsx) 작성기 (의존성 없음)
lib/zip.js           ZIP 작성기 (한글 파일명)
lib/seal-cert.js     봉인 인증서
lib/cades.js         PAdES 서명 생성·검증 (B-B / B-T)
lib/tsa.js           RFC 3161 타임스탬프 요청·검증
lib/asn1.js          ASN.1·CMS 공통 도우미
lib/phone.js         전화번호 정규화·가리기
scripts/mail-catcher.js  연습용 가짜 메일 서버
test/flow.test.js    전체 흐름 자동 테스트 16개 (실제 SMTP 발송, OpenSSL 서명 검증 포함)
test/tsa.test.js     타임스탬프 자동 테스트 7개 (가짜 TSA, OpenSSL ts -verify, TSA 장애 시 B-B 대체)
test/fake-tsa.js     테스트용 가짜 TSA 서버
```

## 아직 없는 것

- 휴대폰 문자(SMS/알림톡) 발송·인증 — 유료 서비스 연동 필요
- 장기 검증(PAdES B-LT/LTA: 폐기 정보·문서 타임스탬프 보관), 공인 문서서명 인증서
- 여러 담당자 계정
- 법적 효력: 전자서명법상 당사자가 합의한 전자서명은 효력을 가질 수 있지만, 중요한 용도라면 법률 검토를 받으세요.
